# Teammate 2: R3D-18 RD video classification

Status: assignment and implementation brief, 2026-11-10; no new model implemented
or trained by this document. Read the [shared protocol](../MODEL_COMPARISON_PLAN.md)
first; it owns data, optimization, cache integration, evaluation and reporting rules.

## Goal

Train a one-channel torchvision **R3D-18** classifier from scratch on ERDES
`non_rd_vs_rd` and compare it with our completed U-Net++ encoder classifier under
the inherited training recipe. R3D adds residual connections and learns joint
spatiotemporal features. This is a new controlled baseline, **not the paper's
deeper MONAI ResNet reproduction**.
[Official builder](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.video.r3d_18.html),
[source notes](../research/video-model-comparison-sources.md).

## Completion criteria

one-channel/logit contract, changed-data rejection, selected-checkpoint reload and
resume identity. Existing applicable tests still pass. The model report links

validation predictions. No test score is used to choose a model or threshold.
Do not claim a CUDA run, 50 completed epochs or a performance gain without logs.
