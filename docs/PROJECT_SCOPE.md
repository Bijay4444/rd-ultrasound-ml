# Project scope

Theme: retinal detachment analysis from ocular ultrasound using ERDES.
The course project is approved to use ERDES according to the existing initialization
brief. A rubric and approval document were not available for independent checking.

Motivation: learn reproducible ML research on a meaningful medical imaging task.
Personal experience is motivation, not scientific evidence.

Likely primary task: RD versus non-RD. Possible secondary task: macula intact versus
detached. Verify label definitions and positive-class encoding before implementation.
Candidate contributions: false-negative analysis, class imbalance, probability
confidence/calibration, reliability, or sample-level error estimation. These are
options, not commitments. Reproducing a baseline can establish a reference, but
an achievable research question and controlled comparison should be agreed with
the professor before claiming a contribution.

Not yet decided: question/hypothesis, architecture, final Python/dependencies,
split policy, preprocessing, metrics, compute budget, and secondary task.
Selection depends on the paper, metadata audit, literature, course rubric, and
available compute. Investigate patient/eye grouping before splitting videos.
