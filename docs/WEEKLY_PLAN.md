# Proposed weekly plan

Relative project weeks, not confirmed course deadlines. Revise after obtaining the rubric.

## Week 1 — Foundation

- Objective: Foundation.
- Deliverables: Paper notes, upstream review, scope and learning notes.
- Presentation evidence: Show inspected sources and open questions.
- Risks/blockers: Rubric/paper unavailable.
- Next milestone: Data audit.

## Week 2 — Dataset audit

- Objective: Dataset audit.
- Deliverables: Provenance, counts, labels, patient/eye grouping and duplicate checks.
- Presentation evidence: Show audit summary and split policy.
- Risks/blockers: Missing grouping metadata or video access.
- Next milestone: Small baseline.

## Week 3 — Small baseline

- Objective: Small baseline.
- Deliverables: One end-to-end run on a documented development subset.
- Presentation evidence: Show input-to-metric path and sanity checks.
- Risks/blockers: Codec or compute limits.
- Next milestone: Full baseline.

## Week 4 — Reproducible baseline

- Objective: Reproducible baseline.
- Deliverables: Locked environment, configuration, seeds and validation metrics.
- Presentation evidence: Show repeatable commands and baseline table.
- Risks/blockers: Runtime and imbalance.
- Next milestone: Error analysis.

## Week 5 — Error analysis

- Objective: Error analysis.
- Deliverables: Confusion matrix and false-negative examples on development data.
- Presentation evidence: Show failure categories and limitations.
- Risks/blockers: Too few positive cases.
- Next milestone: First experiment.

## Week 6 — First experiment

- Objective: First experiment.
- Deliverables: One hypothesis and controlled comparison.
- Presentation evidence: Show fixed/changed variables and validation results.
- Risks/blockers: Inconclusive effect.
- Next milestone: Reliability or second comparison.

## Week 7 — Reliability or second experiment

- Objective: Reliability or second experiment.
- Deliverables: Calibration/confidence if selected; otherwise another justified comparison.
- Presentation evidence: Show held-out fitting protocol and metrics.
- Risks/blockers: Overfitting validation or small sample.
- Next milestone: Final comparison.

## Week 8 — Final synthesis (Week 8+)

- Objective: Final synthesis (Week 8+).
- Deliverables: Secondary task only if feasible; final comparison, test evaluation, report and slides.
- Presentation evidence: Show methods, limitations, attribution and team contributions.
- Risks/blockers: Deadline/compute pressure.
- Next milestone: Submission.
