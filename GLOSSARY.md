# Project glossary

**Attribution map**: A spatial and temporal summary of contributions to a chosen
model score. It is not a ground-truth anatomical annotation.

**Frozen checkpoint**: A saved model state selected using a declared validation
rule and fixed before its subsequent evaluation.

**Occlusion check**: A sensitivity experiment measuring how a model score changes
when a specified region of its input is replaced.

**Outcome-stratified case panel**: A fixed collection of examples selected from
correct positive, correct negative, false positive and false negative predictions.
It illustrates outcomes rather than estimating their population frequencies.
